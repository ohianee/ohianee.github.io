# ohianee.github.io

Código fuente del portfolio personal de Naiara Ohiane Gordillo Ferreiro, publicado con GitHub Pages en [ohianee.github.io](https://ohianee.github.io).

Sitio estático (HTML + CSS, sin build step) con:

- Perfil profesional y habilidades técnicas.
- Proyectos destacados: [DEI Report](https://github.com/ohianee/dei-report) (TFM), [análisis de secuencias de ADN](https://github.com/ohianee/wordsequenceanalysis) (TFG) y ChemiInspection (IRTIC).
- Experiencia y formación.
- CV descargable y enlace de contacto.

## Desarrollo local

Al no usar ningún framework ni build step, basta con abrir `index.html` en el navegador, o servirlo con cualquier servidor estático, por ejemplo:

```bash
python -m http.server 8000
```
